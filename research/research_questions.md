# Research Questions

## RQ1: Python-Specialized Tokenization

Does a Python-specialized tokenizer improve compression, representation of Python syntax, identifier handling, and downstream model quality compared with appropriate general-purpose tokenizer baselines?

## RQ2: Quality-Over-Quantity Data Curation

Can a carefully curated, validated, Python-only dataset produce stronger code-model behavior than larger but noisier Python corpora at the same approximate model scale?

## RQ3: Compact Python-Specialized Model Competitiveness

Can an approximately 160M-parameter Python-specialized model be competitive with larger or more general baselines on Python code generation, completion, syntax validity, and educational examples?

## RQ4: Neurosymbolic Feedback

How much do AST validation, future Knowledge Graph validation, and tooling feedback improve generated Python code quality, rejection rates, repair success, and reliability?

## Evaluation Discipline

These questions must be answered only with recorded experiments. Do not infer success from implementation completion, isolated anecdotes, or unregistered runs.
